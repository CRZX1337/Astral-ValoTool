Features

Three tools, one process, no waiting around.

It's one C# app: an embedded ASP.NET Core Web API behind a native WebView2 window. Open the home menu and pick a tool, or skip the UI entirely and drive the local REST endpoints from your own scripts.

Locks the instant pre-game opens

Detects the pre-game lobby and locks your agent through RadiantConnect. It watches your local game client for the state change rather than the screen, so there is no mouse to move and nothing to react to.

Pre-game detection Per-map overrides 0–10 000 ms timing Match de-duped

Rank & session tracker

Current tier and RR, wins and losses since you sat down, and the RR delta on every recent competitive match. Refreshes when you ask it to, never on a timer.

Auto-queue

Requeues when a match ends, confirms the party ready check, and picks the queue. It refuses to queue mid-match and stops itself after a set number of games.

Live state stream

One Server-Sent Events feed on /api/events carries every tool's state, tagged by module — so the UI and any external client stay current without polling.

Keeps running in the tray

Closing the window sends Astral to the system tray. Any running loop keeps going — right-click the icon to stop or exit.

Real agent art

Agent portraits, role icons and rank badges are fetched from valorant-api.com at runtime, so a new agent or tier shows up without an update.

Nothing to install

The whole web frontend is embedded in the binary. One self-contained Astral.exe, and nothing gets written next to the executable.

How it works

Open it, pick a tool, stop thinking about it.

Start Astral

Idle
  1. 1

    Launch it, whenever

    Start Astral.exe either before or during a Valorant session. It binds Kestrel to a random loopback port and opens the desktop UI.

  2. 2

    Pick a tool from the home menu

    Instalock, rank tracker, or auto-queue. Each one is its own screen with its own live status, and the home cards show what every tool is doing without opening them.

  3. 3

    Arm the loop

    Instalock watches for pre-game and fires — hover, then lock, on whatever delays you set. Auto-queue watches for the end of a match and puts you back in.

  4. 4

    Close the window

    It minimizes to the notification tray and keeps going. The loops survive the window, so the next queue is already covered.

Local API

Drive it from your own scripts.

On startup, Astral binds Kestrel to a random loopback port. It's 127.0.0.1 only, so nothing on your network can reach it, and the state-changing routes reject any request carrying a foreign Origin header. Scripts don't send one, so curl and PowerShell work as-is.

GET/api/agents

Agent list from the local RadiantConnect enum

GET/api/agent-assets

The same list enriched with portraits, roles and colours

GET/api/state

Current lock state

GET/api/events

Every tool's state pushed on every change (SSE), tagged by module

POST/api/lock

Start monitoring, or re-aim a running loop at another agent

POST/api/stop

Stop monitoring

GET/api/options

Settings plus the list of maps they can refer to

PATCH/api/options

Partial settings update, validated and persisted

GET/api/tracker

Rank, session totals and recent competitive matches

POST/api/tracker/refresh

Re-read rank and match history from Riot

POST/api/tracker/session/reset

Re-anchor the session to now

GET/api/autoqueue

Auto-queue state, party state and eligible queues

POST/api/autoqueue/start

Run the automation loop

POST/api/autoqueue/queueing

Enter or leave the queue right now

PATCH/api/autoqueue/options

Auto-queue settings and the queue list

Install

Grab the exe, or build it yourself.

The release is a single self-contained Astral.exe — no installer, no runtime to add, nothing written next to it. Prefer to compile? Three commands.

Download Astral.exe

You'll need

Windows 10 or 11

.NET 10.0 SDK, if you're building from source

Edge WebView2 Runtime, which is already on most modern Windows installs

Valorant running on the same machine

Configuration

Changes made in the UI or through the API are saved to %APPDATA%\Astral\settings.json. Defaults come from appsettings.json.

HoverDelayMs

Wait before hovering the agent in pre-game. 0–10000 ms, default 0.

LockDelayMs

Extra wait between hovering and clicking Lock. 0–10000 ms, default 0.

PostLockDelayMs

Idle time after locking, before the state resets. 0–10000 ms, default 5000.

MapAgentOverrides

Maps exact map names to canonical agent names. Empty by default.

  1. Clone it

    git clone https://github.com/CRZX1337/Astral-ValoTool.git
cd Astral-ValoTool

  2. Run it

    dotnet run -c Release

  3. Or publish a standalone exe

    Squeezes the runtime, the frontend and the WebView2 loader into a single self-contained Astral.exe (~62 MB) under bin\Publish\SingleFile\. That one file is everything you need to ship. 

    dotnet publish -p:PublishProfile=SingleFile

Details

Questions, and who built what.

What is it actually doing?

Astral talks to the Valorant client's own local API through RadiantConnect. Instalock subscribes to pre-game events and calls select then lock; the tracker reads your MMR and competitive updates; auto-queue drives the party endpoints. No screen reading, no input simulation, and no account login — it uses the tokens the running client already holds.

Use at your own discretion.

Where does it store things?

Settings live in %APPDATA%\Astral\settings.json, with appsettings.json as the fallback. The embedded browser keeps its profile in %LOCALAPPDATA%\Astral\WebView2.

Nothing gets written next to the executable.

Can I script it instead of using the UI?

Yes. Everything the desktop UI does goes through the same local REST API, and /api/state/stream pushes state changes as Server-Sent Events so you never have to poll. See the API section.

Is anything exposed to my network?

No. Kestrel binds to a random port on 127.0.0.1 only, so nothing on your network can reach it.

Do I have to keep the window open?

No. Closing it sends Astral to the notification tray and any running loop keeps going. Right-click the tray icon for Open, Stop locking or Exit.
